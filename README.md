## About

I’m a third-year Computer Science student at FAST-NUCES who enjoys turning ideas into useful software. My projects span AI search and constraint optimization, full-stack applications, and operating-systems concepts. I’m currently open to software development and AI internship opportunities.

## Featured Projects

### [AI-Powered Warehouse Robot Scheduler](https://github.com/Abdullah-Karim123/Ai-Powered-Warehouse-Robot-Scheduler)

A full-stack warehouse simulation that assigns pickup-and-delivery tasks to a mixed fleet of robots. It combines A* route planning with terrain and battery costs, and an OR-Tools CP-SAT scheduler for robot-task assignment.

**Stack:** Python · FastAPI · OR-Tools · A* · React · TypeScript

### [CricMate — Cricket Match Management](https://github.com/Abdullah-Karim123/CricMate---Cricket-Match-Management-System)

A tournament and match platform with ball-by-ball statistics, admin workflows, role-based access, and a relational data model.

**Stack:** Java · Spring Boot · Next.js · TypeScript · PostgreSQL · Supabase

### [Multi-User Document Editor](https://github.com/Abdullah-Karim123/Multi-User-Document-Editor)

A multi-process document editor demonstrating reader-writer synchronization and priority-based access with POSIX file locks, semaphores, shared memory, and UNIX signals.

**Stack:** C · POSIX IPC · Semaphores · Shared Memory · UNIX Signals
